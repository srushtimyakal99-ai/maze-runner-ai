About AI Maze Runner

AI Maze Runner is an interactive maze game where the player must reach the exit while avoiding an AI-controlled enemy. The enemy uses the Breadth-First Search (BFS) algorithm to dynamically find a path toward the player.

🧠 BFS AI

The enemy uses Breadth-First Search for dynamic pathfinding.

🎮 Player Control

Use the arrow keys or WASD to move through the maze.

⚡ Difficulty

Choose Easy, Medium or Hard.
